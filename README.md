# Minimum AI Curriculum

一份尽可能短的 AI 自学课程表。从编程基础开始，逐步获得进入 AI 研究所需的核心能力。第一部分快速涵盖了一些基础知识，比如编程语言入门、离散数学、概率统计、数据结构与算法等。第二部分为开始学习人工智能打下地基。第三部分开始学习 AI 的具体细分领域。笔者认为，在 AI 时代，第一部分应尽可能快的学完，开始尝试在codex的辅助下做项目。

## 本地运行

```bash
npm install
npm run dev
```

## 生产构建

```bash
npm run build
```

构建产物会生成在 `dist/` 目录中，可直接部署到静态网站托管服务。
